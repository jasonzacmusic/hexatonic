The red pen

Six defects, worst first

1

Three flat keys spell chords wrongMusical

On /harmony → Pair atlas, three of the twelve pair exercises print a chord symbol whose notes contradict the symbol. A student reading D♭ minor is shown an E natural where the flattened third belongs. Thirty individual chord displays are affected across eight entry-and-key combinations.

ShownD♭m  =  D♭   E   A♭
CorrectD♭m  =  D♭   F♭   A♭
ShownD  =  D   G♭   A
CorrectD  =  D   F♯   A

Cause · src/lib/theory/custom.ts:61 — spellSet charges 10,000 per accidental but only 2,000 for reusing a letter, so it prefers “D♭ E♭ E G♭ A♭ B♭” (letter E twice, letter F unused) over the correct “D♭ E♭ F♭ G♭ A♭ B♭”. For six notes one letter per degree is always available, so that weighting is backwards.

Fixed. A repeated letter now costs more than one accidental, and accidental direction carries real weight — that is what separates this from the blues, where the repeat is correct. The Atlas also spells for its chords, so D♭ reads D♭ D F F♯ A♭ A and gives D♭ major plus D major. Verified in the running app.

Affected: Dorian pair (D♭, A♭) · Phrygian pair (D♭, A♭, E♭) · Major triads a semitone apart (D♭, A♭, E♭). All other keys are correct.

One honest caveat: the semitone pair cannot be spelled as both a clean scale and two clean triads — C + D♭ genuinely needs D♭ D F F♯ A♭ A. For that entry the fix is to spell per triad, since the Atlas exists to show chord symbols.

2

Double accidentals in the symmetric scalesNotation

Whole-tone, augmented and Petrushka use a fixed letter template, so in sharp keys they climb into double sharps that no musician would write. B whole-tone comes out B C♯ D♯ E♯ F𝄪 G𝄪; the conventional spelling breaks the letter run to read B C♯ D♯ F G A.

Cause · src/lib/theory/scales.ts — the eight-note octatonic searches for the cheapest letter assignment, but the six-note symmetric families never got that treatment and still use a hard-coded letters array.

Fixed. Those families now fall back to the letter search, but only when the template actually produced a double — so the blues ♭5/5 pair, the major blues ♭3/3 pair and C augmented are untouched. B whole-tone now reads B C♯ D♯ F G A.

Affected: whole-tone in A, E, B, F♯ · augmented in E, B, F♯, D♭ · Petrushka in D♭, A♭. The existing sweep passes them because it only asserts the accidental is drawable, not that it is sensible.

3

Key signature chosen by list order, not by fitNotation

A hexatonic sits inside two parent major scales — that ambiguity is the whole point of the modal-intersection names. The app picks whichever parent appears first in its KEYS array rather than the one that fits, so 29 of 72 rotations print a key signature containing an accidental the scale never sounds.

ExampleC Dorian/Aeolian = C D E♭ F G B♭
UsesE♭ major — 3 flats, the A♭ never sounds
BetterB♭ major — 2 flats, both used

Cause · src/lib/theory/scales.ts:427 — findParentScale returns the first match instead of the one with no unused accidentals.

Fixed. It now prefers the parent that spends every accidental it prints, keeping list order only as the tiebreak between two equally clean parents. C Dorian/Aeolian now takes B♭ major.

Nothing renders wrongly here — the notes are right and accidentals are drawn correctly against whichever signature is chosen. It just reads as noisier than it needs to.

4

The swing feel never swingsLow

The vamp scheduler has a triplet-shift for offbeats, but it only fires when a comp hit lands on a half-beat — and the swing pattern places chords on beats 1 and 3 and bass on all four. Every hit is a whole beat, so the shift is unreachable code.

Cause · src/lib/audio/engine.ts:404 — dead branch. The drill scheduler's own swing (line 337) does work correctly.

Fixed. The swing comp is now beat 2 plus an anticipation on the swung “and of 4” — the standard two-feel — so the triplet shift fires and is audible. A test asserts the hit lands a triplet late, and that the straight feel does not move.

The result is not musically wrong — a two-feel with chords on 2 and 4 is a legitimate comp. The real limitation is that no vamp has swung eighths at all.

5

The service worker caches failed responsesLow

The network-first branch stores every response it receives without checking the status, so a transient 404 or 500 gets written into the offline cache and then served back as the offline fallback until the next deploy.

Cause · public/sw.js — needs a res.ok guard before cache.put. One line.

Fixed. Both cache branches now store only a successful same-origin response.

6

Control borders sit at 1.24:1Access

Text contrast is fine everywhere — see below. But --line against --surface measures 1.24:1, and WCAG requires 3:1 for the boundary of a user-interface component. Controls whose only affordance is that border are effectively edgeless for a low-vision user.

Cause · src/app/globals.css — --line:#2A2523 on --surface:#14120F.

Fixed. Selects and segmented controls take a new --line-control token measuring 3.30:1. Decorative hairlines keep --line, so the page does not turn into a grid of boxes.

What I could not break

Held up under brute force

  • Every scale, every key, every rotation. All families across all twelve keys build without error, ascend, sound each pitch once, stay inside an octave, and label their degrees with the intervals actually sounding.
  • The Pair Atlas exact-cover proof. All twelve entries in all twelve keys — the two shapes never share a note and always account for the whole scale. No throw, in 144 combinations.
  • The Movement Lab. Twelve keys × six rotations, plus both octatonics, with no unhandled throw — which matters because these run inside render, where an exception would white-screen /harmony.
  • The Forte table. I recomputed every prime form by hand, including the 6-Z47 claim that minor and major blues are the same set class. All correct.
  • Colour contrast. Every text token passes AA on every surface — the roadmap's guess that muted failed is wrong. It measures 4.53 to 5.20.
  • Voicings and playback ranges. Every generated exercise stays inside the piano and ascends within each chord. All 17 Salamander samples are present.

The roadmap is out of date

  • “CACHE = hexatonic-v1 must be bumped on every deploy.” Now build-stamped with the git SHA — verified live as sw.js?v=da7ec71….

  • “Accessibility never audited — reduced motion unknown.” prefers-reduced-motion is handled in globals.css.

Still genuinely open

Technical debt I confirmed is real

  • Zero component or end-to-end tests. All 249 tests are engine-level. Nothing at all covers React behaviour, and nothing would have caught a broken button.
  • Thin ARIA. Ten interactive files carry no ARIA attributes at all — including the ear-training game, the custom scale builder, the MIDI panel and the Tihai lab. There is no skip-to-content link.
  • No automatic deploy. Vercel here is manual; production had drifted five days behind GitHub before today. This is the one I would fix first — it silently un-ships your work.
  • Leftovers. prototype/ is still in the repo, and transpose is still a prop fixed at one octave with no interface.
  • No analytics. Still no idea which drills people actually use.
